# llm-data-analytics-assistant
Developed a conversational data analytics assistant using LLMs and Generative AI to convert natural-language questions into SQL queries and retrieve database insights. Implemented SQL generation, query execution, error handling, and evaluation using execution accuracy across easy, medium, and hard queries.
Conversational Data Analytics Assistant

An LLM-powered data analytics assistant that converts natural-language questions into SQL queries, executes them against a relational database, and returns accurate data-driven results through a conversational interface.

Key Features

Natural Language → SQL generation
LLM-based query understanding
Automated SQL execution
Error handling and retry mechanism
Query result validation
Difficulty-based evaluation
Execution accuracy measurement
Gemini LLM integration
